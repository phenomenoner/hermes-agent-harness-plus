Public-safe add-ons for Hermes Agent

Evidence, recall, and release hygiene for agent work.

Harness Plus is a small public toolbox around Hermes Agent. It packages optional adapters, MCP sidecars, skills, and ops rules that make long-running agent work easier to follow, search, and share.

Keep the map

Task Canvas stores concise progress nodes and keeps raw evidence in referenced files, so the agent does not have to carry every log in active context.

Recall locally

Qdrant helpers index public-safe skills and recent sessions on your own machine. Search stays local unless you choose otherwise.

Publish safely

Checklists and labels help keep reusable harness code separate from private identity, private channels, credentials, and local datasets.
